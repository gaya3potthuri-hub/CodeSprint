# CodeSprint ✦ Learn · Practice · Grow

A vibrant, cartoon game-style coding platform where learners explore 4 floating technology islands (Python, SQL, Java, AI), progress through village level-maps, and master real programming concepts through interactive drills and challenges.

## Key Features

- **4 Floating Islands World**: Explore Python, SQL, Java, and AI isles in a bright cartoon game realm with bobbing animations, lock requirements, and mastery stars.
- **Village Progression Map**: Sequential level-map paths of numbered nodes with 1–3 star ratings, prerequisites, and topic drills.
- **Heart Lives & Combo System**: 5-heart life counter with a Game Over screen, alongside a streak combo multiplier pop-up rewarding consecutive correct answers with bonus XP.
- **Daily Quests & Coins Treasury**: Daily quest missions rewarding gold coins and XP, with animated reward chests and celebratory confetti on level completion.
- **Cadet Dossier & Player Card**: Game profile card with an 8-option avatar picker, editable username, rank progression, and an achievement badge shelf.
- **Day & Night Game Themes**: Curated light (sky-blue ocean) and dark (deep night sky) game palettes with responsive audio sound effects.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
